# Tekstury zwierzat z Minecraft 1.12.2

Renderer korzysta z modeli MCP 9.40 i oczekuje oryginalnych tekstur 64x32 px pod sciezkami:

- `assets/entity/pig/pig.png`
- `assets/entity/cow/cow.png`
- `assets/entity/sheep/sheep.png`
- `assets/entity/sheep/sheep_fur.png`

Sa to odpowiedniki plikow gry:

- `textures/entity/pig/pig.png`
- `textures/entity/cow/cow.png`
- `textures/entity/sheep/sheep.png`
- `textures/entity/sheep/sheep_fur.png`

Dla zgodnosci wstecznej obslugiwane sa tez plaskie nazwy bez podkatalogow, np. `assets/entity/pig.png`.
Bez tych plikow gra nadal dziala i wyswietla modele w kolorach awaryjnych.
